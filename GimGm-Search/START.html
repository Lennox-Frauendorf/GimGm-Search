🚀 Los geht's!

Schritt 1: Öffne die Datei index.html in deinem Browser

Doppelklick auf "index.html" oder Rechtsklick → "Open with" → Browser
⚠️ Tipp: Verwende einen modernen Browser wie Chrome, Firefox oder Edge für beste Ergebnisse!

🎮 Zwei Wege zum Starten

Option A: Demo testen (Schnellstart) 🎯

  • 1. Die App lädt → Klick "Demo Nutzer"
  • 2. Du wirst ins Dashboard weitergeleitet
  • 3. Demo-Suchverlauf & Statistiken sind vorhanden
  • 4. Teste alle Features ohne dich zu registrieren!

Option B: Neues Konto erstellen 📝

  • 1. Klick "Registrieren"
  • 2. Fülle das Formular aus
  • 3. Passwort: mindestens 6 Zeichen
  • 4. Klick "Konto erstellen"
  • 5. Melde dich an

✨ Die besten Features

  • Suchverlauf: Klick die Verlauf-Icon (📜) um alle deine Suchen zu sehen
  • Profilbild: Öffne dein Profil und klick die Kamera um ein Bild hochzuladen
  • Statistiken: Sehe wie viele Suchen du gemacht hast und wieviele heute
  • Tastaturkürzel: Drück Strg+Enter um zu suchen oder Esc um Panels zu schließen
  • Dark Mode Vorbereitung: Das Design unterstützt zukünftige Erweiterungen

🛠️ Technologie

Frontend: HTML5, CSS3, Vanilla JavaScript

Speicher: LocalStorage (Daten bleiben im Browser)

Icons: Font Awesome

Design: Glassmorphism, Gradients, moderne Animationen

📂 Dateien

  • index.html - Hauptdatei der App
  • css/styles.css - Alle Designs & Animationen
  • js/app.js - Gesamte Funktionalität
  • assets/default-avatar.svg - Standard-Profilbild
  • README.md - Komplette Dokumentation
